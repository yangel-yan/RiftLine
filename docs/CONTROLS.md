# RIFTLINE — Editor 游玩指南

使用 Unity **6000.6.7f1** 打开项目，打开 `Assets/Riftline/Scenes/Riftline.unity`，进入 Play Mode，并点击 Game 窗口使其获得键盘焦点。

在主菜单点击“立即开跑”，直接进入首个已解锁且尚未通关的契约；也可点击“选择契约”挑选关卡。首页未选中其他按钮时，`Enter` 执行同样的快捷开跑。第一契约为 **60 秒**：晶片连收、换道、跳跃、滑铲、转弯、相位穿墙与档案分岔都在这一分钟内出现。

开场目标是取回档案并抵达撤离点。航道外的安保无人机随剩余生命逼近；它是追逐反馈，失败仍由现有障碍与生命规则决定。真正拾取档案后，HUD 切换为“前往撤离点”，最后 **15 秒**出现撤离门。落地、连收和相位提供局部能量与声音反馈；低闪光与减少粒子设置会调整这些效果。

| 操作 | Editor 键盘 / 鼠标 | 默认手柄映射 |
| --- | --- | --- |
| 换道、转弯、分岔 | `A / D` 或左右方向键 | 任一摇杆左右 |
| 跳跃 | `Space` | 右手 A / 左手 X |
| 滑铲、空中快速落地 | `S`、下方向键或 `Ctrl` | 右手 B / 左手 Y |
| 相位穿越 | `Shift` 或 `E` | 任一扳机 |
| 暂停 | `Esc` | 左手菜单键 |
| 切换舒适遮罩 | `F2` | 任一摇杆按下 |
| 菜单操作 | 鼠标点击、滚轮、拖动 | 主手射线、扳机、摇杆滚动 |
| 重置朝向 | 局前或暂停中长按 `Space` 一秒，或点击按钮 | 局前或暂停中长按 A / X 一秒 |
| 下一契约 / 重试 / 恢复 | 结算 / 暂停中按 `Enter`，或点击按钮 | 对应菜单按钮 |

`Enter` 优先提交当前选中的 UI 按钮。没有选中按钮时，首页可快捷开跑，暂停页可恢复；通关且下一契约已解锁时，结算页进入下一契约，失败时重试本关。设置、档案等子页面不会触发开局或恢复。

换道和转弯只在按下沿触发。连续换道需要先松开方向键；摇杆须回到中心死区。转弯和分岔预告出现后，方向输入优先用于选择出口。

每局有 **3 格生命**，左上方血条同步显示剩余格数。普通障碍碰撞扣 **1 格**，清空晶片连收并把倍率重置到 **1.0**，随后获得 **1.25 秒**短暂无敌；同一个障碍只结算一次伤害。生命归零、跌入断层、踏入塌陷或错过转弯会失败。教学也会真实扣血。暂停和恢复倒计时冻结伤害保护与游戏内反馈计时。

连续拾取晶片形成连收；首次达到 **5 / 10 / 20** 连收时，每档补充 **20%** 相位能量并增加 **0.25** 倍率。漏收晶片或碰撞打断连收。晶片带有亮色光环，拾取时飞向跑者，音高随连收递增。

相位槽充满后才能穿越，持续 **0.8 秒**。相位使用降低连段倍率 **0.5**，最低 **1.0**。普通近失误补充 **20%** 能量，移动危险补充 **30%**。相位期间不会再次获得近失误充能。

设置支持简体中文 / English、坐姿 / 站姿、三种转向方式、四档遮罩、左右主手、跳跃 / 滑铲互换、扳机选择、震动和独立音量、视觉辅助、字幕、字号、跑者距离与休息提示。互换跳跃 / 滑铲也会交换对应 Editor 按键。

平滑转向与两步转向会旋转 XR Origin 上方的导航节点，头部追踪的局部姿态仍由设备控制；固定视野模式展开道路、保持观察朝向。转向模式修改从下一局生效，避免在暂停时突然改变视野。首次开跑倒计时为 **1 秒**。窗口失去焦点会暂停；恢复焦点后按 `Enter`，经过三秒倒计时再继续。

每区完成五个契约后开放下一区域；完成船坞第六个契约后开放无尽。分岔支线包含不同档案，应重玩并选择另一路。档案拾取立即保存；失败或“安全结束本局”不会丢失已拾取档案。七件付费晶片外观均为纯外观，通过游玩解锁。

存档保存在 Unity 的 `Application.persistentDataPath/Riftline`，使用三份轮转文件和完整性校验。Editor 验收使用独立临时目录，不修改正常游玩进度。

开发菜单提供 `Riftline/Create or Update Game Scene`、`Riftline/Configure Generated Art`、Core 验证与完整 Editor 验收。重建场景应在 Edit Mode 执行；普通游玩直接打开现有场景即可。

本交付的验收范围为桌面 Unity Editor。手柄映射已实现，实际 PICO 输入、双目画面、佩戴舒适性和设备性能不属于此次验证范围。

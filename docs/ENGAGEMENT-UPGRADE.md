# Riftline — UI、生命与开场升级

2026-10-26 · Unity 6000.6.7f1 · 桌面 Editor Play Mode

这一轮调整了首页、游戏内 HUD、碰撞生存规则和第一分钟的内容节奏。项目继续使用此前由 Unity AI Generator 生成的角色、场景、动作图标及音频资源。

## 实际变化

- 首页扩大主视觉与按钮，提供「立即开跑」，直接选择第一个已解锁且未通关的契约。已通关后继续推荐下一契约。
- HUD 分开显示三格生命、距离与进度、分数与倍率、晶片连收、相位充能。动作提示只在当前危险或转弯出现时显示。
- 普通障碍碰撞扣一格生命，重置连收和倍率，产生受伤提示、红色边框、音效和震动。1.25 秒保护使用模拟时间；同一障碍不会重复结算伤害。
- 教学碰撞也真实掉血。生命归零、跌入断层、塌陷和未完成转弯会失败。鼠标和 Enter 重试均恢复三格生命，并保留原契约。
- 晶片增加光环与拾取飞行动画。5 / 10 / 20 连收各获得 20% 相位充能与 0.25 倍率；拾取音高随连收递增。
- 第一个契约缩短为 60 秒。前段连续晶片引导换道、跳跃和滑铲；27 秒获得相位充能，30 秒穿墙，随后进入档案分岔。39 秒起再次安排关键动作，首次失误后仍可补完教学。
- 首次开跑倒计时为 1 秒，暂停恢复仍为 3 秒。保护、拾取飞行及游戏内反馈冻结；降低闪光设置限制受伤边框强度。

复查还修正了子页面 Enter 误开局 / 恢复、暂停期间受伤字幕过期、英文最大字号下首页文案被截断，以及自定义渐变缺少 CanvasRenderer 的问题。Enter 优先提交当前选中的 UI 按钮；未选中按钮时才使用首页、暂停或结算快捷操作。

## 游玩与验证

普通键盘和鼠标事件通过实际 Unity Input System、EventSystem 和 UI raycast 执行。没有直接修改生命、跳过障碍或加速游戏。使用独立临时存档，正常游玩进度不受影响。

完整首关实测：第一次撞箱后以 **2 格生命**完成 60 秒契约，收集 **43 个晶片和 1 份档案**，得分 **18,604**。首通结果与进度保存成功。

独立死亡 / 恢复实测：三次碰撞依次形成 **3 → 2 → 1 → 0**，鼠标重试和 Enter 重试均恢复 **3 格生命**、清空伤害及连收，并留在契约 0。回到首页后的快捷开跑选择契约 1。

界面验证包含中英文首页、契约、装束、档案与设置，英文 1.4 倍字号、重复装束预览、鼠标滚轮和返回按钮。伤害保护、受伤字幕及相位能量经过暂停和恢复倒计时验证。全部成功游玩阶段未观察到运行时错误。

Core 验证通过 **95 组检查、504 个独立见证、10,000 个种子、20,000 条完整序列**；独立见证也检查安全路线结束时仍为三格生命、零伤害。
